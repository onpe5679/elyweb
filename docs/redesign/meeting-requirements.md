## 🎯 게임 상세 화면 참고

사용자는 ‘스트리밍 플랫폼 느낌’에 대해 아래 두 이미지를 제공했다. 화면 구성을 참고한 게임 소개 디자인으로 해석하며, 서비스의 모든 기능을 도입한다는 요구로 확대하지 않는다.

| 자료 | 화면에서 확인한 구성 | 게임 상세 적용안 |
| --- | --- | --- |
| [스트리밍 상세 1 — 넷플릭스](references/07-streaming-detail-netflix.png) | 큰 배경 장면, 작품 로고, 주요 행동 버튼, 본문으로 이어지는 어두운 그라데이션. 하단에 시놉시스와 출연·장르 등 정보가 좌우로 나뉘고 관련 컬렉션이 이어짐. | 게임 키비주얼·로고·트레일러 보기·스토어 이동을 상단에 배치. 아래에는 시놉시스와 작품 정보를 읽기 쉽게 나누고 스크린샷·관련 작품을 연결. |
| [스트리밍 상세 2 — FX 전사 쿠루미](references/08-streaming-detail-anime.png) | 배경 일러스트와 오른쪽 세로 포스터, 왼쪽 작품명·정보·행동 버튼. 소개문 아래로 콘텐츠 탭과 목록이 이어짐. | 가로 배너와 세로 커버가 있는 작품의 배치 기준. 하단의 소개·갤러리·영상·제작진을 일정한 규격으로 구성하는 참고. 탭 사용은 콘텐츠 분량에 따라 판단. |

우선 설계안은 큰 작품 비주얼 → 작품명·주요 버튼 → 시놉시스·기본 정보 → 스크린샷·영상·크레딧·관련 작품이다. 장르, 출시 상태·일자, 플랫폼, 개발·퍼블리싱, 지원 언어 등의 필드는 기존 데이터와 실제 콘텐츠를 확인해 정한다. 모든 게임에서 같은 순서와 정보 위계를 유지하되, 없는 콘텐츠는 빈 영역이나 임의의 정보로 채우지 않는다.

어두운 그라데이션과 대비는 작품 이미지 위의 가독성을 확보하는 참고다. 이 화면만으로 회사 홈페이지 전체의 다크 테마가 확정되는 것은 아니다. 스크린샷의 닫기 버튼도 모달 사용 확정의 근거로 삼지 않는다. 자동 재생, 찜·평점·사용자 리뷰, 에피소드 구매·재생 이력은 별도 요청이 없으므로 요구사항에 포함하지 않는다.

## 💡 게임 체험 아이디어

사용자는 병원×생활 사이트를 보던 중 회의 참여자들이 게임 체험형 아이디어를 즉석에서 떠올린 것이라고 설명했다. 대화록의 반응을 기존 사이트에 구현된 기능을 발견한 것으로 해석했던 부분을 정정한다. 별도의 예시 사이트는 없다.

구상은 클릭에 따라 대사와 선택지를 보여 주는 짧은 체험이다. 사용자는 적용 범위를 **하봄 쪽 게임 페이지 한정**으로 명시했다. 사용할 작품과 장면, 분량, 분기, 사운드, 끝난 뒤의 이동은 아직 정해지지 않았다.

| 적용 위치 | 디자인·기능 방향 | 범위 |
| --- | --- | --- |
| 엘리시안 첫 화면 | 게임 타이틀처럼 보이는 시각 구성과 메뉴·진입 전환을 함께 설계 | 엘리시안의 브랜드 경험. 대사·선택지 체험은 포함하지 않음. |
| 하봄 소속 게임 상세 | 스트리밍형 작품 소개와 연결되는 짧은 대사·선택지 체험 | 하봄 게임에 한정. 하봄 메인 페이지의 필수 진입 과정으로 확대하지 않음. |
| 엘리시안 소속 게임 상세 | 공통 규격에 맞춘 작품 비주얼·정보·영상·스토어 안내 | 하봄용 체험을 전체 게임에 일괄 적용하지 않음. |

같은 게임 상세 컴포넌트를 공유하더라도 체험의 노출 조건은 작품의 브랜드 소속과 실제 체험 콘텐츠 유무를 기준으로 설계한다. 이 조건은 사용자 범위를 구현하기 위한 제안이며, 구체적인 데이터 필드는 구현 시 기존 구조에 맞춘다.

## 📍 현재 구현과 연결되는 부분

현재 공개 홈페이지에는 비전, 통계, 작품 목록, 연혁이 있고, 작품 목록에서 `Old Engine Series`, `하봄 스튜디오`, `별자리 기담집`이 함께 노출된다.[^live]

| 작업 영역 | 현재 코드 | 이후 설계에서 확인할 점 |
| --- | --- | --- |
| 홈페이지 | `apps/web/app/[locale]/page.tsx` | Hero, VisionSection, StatsBar, ProjectsSection, TimelineSection의 순서·구성 재검토. 기존 섹션을 모두 유지해야 한다는 회의 합의는 없음. |
| 게임 상세 | `apps/web/app/[locale]/games/[slug]/page.tsx` | 현재 동적 섹션 렌더링을 공통 소개 규격과 연결. 텍스트·정보·시놉시스·갤러리·영상·스토어 등을 이미 처리하고 있음. |
| 브랜드 분리 | 현재 홈페이지의 시리즈별 작품 구분 | 하봄 전용 화면, 작품 소속, 왕복 이동 방식 설계. 서브도메인은 확정 후 결정. |
| 콘텐츠 관리 | 기존 관리자 앱 `apps/admin` | 새 소개 규격에 맞춰 입력할 수 있어야 한다는 구현상 고려사항. 구체적 관리자 변경은 설계 후 판단. |
| 다국어 | 공개 홈페이지 KR·EN·JP 및 `[locale]` 경로 | 기존 기능으로 확인됨. 회의에서 언어 지원 변경 요청은 발견되지 않음. |

## ✍️ 다음 확인

원고지와 브랜드 참고 자료, 스트리밍형 게임 상세, 게임 체험 아이디어의 출처와 적용 범위, 엘리시안 첫 화면의 디자인·기능 방향까지 연결했다. 다음 설계에서는 엘리시안의 문예적 시각 요소와 게임 타이틀 같은 진입 경험을 한 화면 안에서 조율하고, 하봄 게임 상세에는 별도로 체험 위치를 잡는다. 체험에 쓸 실제 장면·대사·선택지 등 콘텐츠는 아직 미정이다.

사용자의 시안 제작 요청에 따라 메인·하봄·게임 상세와 연결 페이지를 실제 코드로 구현했다. 검증·미리보기·남은 콘텐츠 항목은 [시안 검토 문서](prototype-review.md)에 기록했다. 운영 배포는 수행하지 않았다.
