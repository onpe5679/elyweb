# 독립 시안 — 「원고지 위의 스튜디오」

`DESIGN_BRIEF.md`를 바탕으로 만든 스튜디오 엘리시안 리디자인 시안입니다. 화면은 `screens/`에 있습니다.

## 방향

| | 엘리시안 | 하봄 스튜디오 |
| --- | --- | --- |
| 바탕 | 종이색, 먹색 글자, 인주(주홍) 한 점 | 크림, 플럼 글자, 로즈 핑크 + 버터 옐로 |
| 서체 | Noto Serif KR/JP(본문·제목), Cormorant Garamond(라틴), IBM Plex Sans KR·Mono(UI) | Jua, M PLUS Rounded 1c, IBM Plex Sans KR |
| 모티프 | 원고지 칸(제목·장 번호·배경), 판권면 같은 정보 표, 재단선 | 둥근 카드, 말풍선, 동그라미 장식 |
| 작품 화면 | 어두운 극장형 히어로 → 종이 지면 | 밝은 둥근 히어로 카드 |

- **첫 화면(타이틀 화면)**: 「스튜디오 / 엘리시안」을 원고지 칸에 조판하고, 오른쪽에 엘리시안 작품 4편의 키 비주얼을 띠로 쌓았습니다. 한 작품의 사이트처럼 보이지 않게 하려는 장치입니다. 메뉴(이야기 시작 · 작품 목록 · 스튜디오 · 소식 · 하봄 스튜디오 · 문의)는 마우스·터치·↑↓/Home/End/Enter로 고릅니다. 이 화면은 입구를 막는 관문이 아니라 페이지 맨 위이며, 스크롤하면 바로 본문(1장 작품 → 2장 스튜디오 → 3장 연표 → 4장 산하 스튜디오 → 5장 소식)으로 이어집니다.
- **작품 목록**: 작품마다 한 지면(큰 그림 + 제목 + 로그라인 + 판권식 정보)을 쓰는 잡지 구성입니다. 이미지와 제목 모두 상세로 연결됩니다. 레이블·시리즈 필터가 있으며, 하봄 작품은 다른 톤의 "삽지"로 구분했습니다.
- **게임 상세 공통 규격**(엘리시안·하봄 공용, 테마만 다름): 키 비주얼 히어로 + 제목·원제·상태·플랫폼·장르·로그라인 + PV/스토어/링크 복사 → 섹션 탭 → 소개(시놉시스·특징) + 기본 정보 → 이미지(라이트박스) → 영상(에피소드 목록형) → 제작진(점선 리더) → 연혁 → 구매·스토어 → 다른 작품. 내용이 없는 블록은 자동으로 숨깁니다. 모든 블록은 기존 CMS 데이터(`games`, `game_sections`)에서 채워지므로, 담당자는 어드민에서 섹션을 추가하는 방식 그대로 이 규격을 채울 수 있습니다.
- **하봄 분리**: `/[locale]/habom`(메인)과 `/[locale]/habom/games/[slug]`(작품)에 별도 레이아웃·헤더·푸터·테마를 두었습니다. 엘리시안 헤더의 「하봄 스튜디오」로 들어가고, 하봄 헤더의 「← 스튜디오 엘리시안」으로 돌아옵니다. 서브도메인으로 옮길 때는 미들웨어 rewrite만 추가하면 됩니다. 레이블 정의는 `apps/web/lib/labels.ts` 한 곳에 있어 산하 스튜디오를 추가하기 쉽습니다.
- **하봄 전용 미니 체험**: 하봄 작품 페이지에만 있습니다(`DEMO_SCRIPTS`에 대본이 있는 작품만). 대사 넘기기(클릭·Enter·Space), 선택지 3개, 분기 엔딩, 처음부터, 닫기(Esc 포함)가 동작합니다. 대본은 **시안용 예시**이며 화면에 SAMPLE 표시가 붙어 있습니다.

## 실행

```bash
pnpm install
pnpm --filter web dev          # Supabase 환경변수가 있으면 실제 DB, 없으면 스냅샷 사용
pnpm --filter web build        # 타입·린트 포함 빌드
node scripts/static-preview.mjs  # 정적 미리보기(아티팩트용) → apps/.static-preview/site
```

- 환경변수가 없으면 `apps/web/lib/snapshot/content.json`(2026-10-20에 운영 사이트 공개 페이지에서 읽기 전용으로 수집한 실제 콘텐츠)과 `public/snapshot/`(경량화한 실제 이미지)을 씁니다. 운영 DB에는 아무것도 쓰지 않았습니다.
- 환경변수가 없으면 문의 폼은 전송·저장·메일 발송 없이 "미리보기 환경" 안내만 보여 주고, `/api/contact`·`/api/upload`도 저장·발송을 하지 않습니다.
- 정적 미리보기는 외부 iframe·이미지를 막는 호스트용이라, 그 빌드에서만 YouTube 영상은 "YouTube에서 보기" 링크, X 타임라인은 바로가기 카드로 바뀝니다. 실제 사이트 빌드는 기존처럼 임베드합니다.

## 실제 콘텐츠로 교체할 부분

1. **하봄 로고** — 원본 코드·업로드 폴더·운영 데이터에서 로고·명함 자료를 찾지 못해 활자로 만든 임시 워드마크(`components/habom/HabomWordmark.tsx`)를 썼고, 하봄 푸터에 "임시 워드마크"라고 표시했습니다.
2. **시안용으로 쓴 문구**(`messages/*.json`): `Habom.copy`, `Habom.aboutBody`, `Home.labelsLead`, `Home.labelsElysianDesc`, `Home.labelsHabomDesc`, `Home.contactLead`, `Contact.lead`, `Press.lead`, `Demo.lead`. 비전·미션·푸터 소개는 기존 문구 그대로입니다.
3. **미니 체험 대본** — `lib/habom/demo-script.ts`. 캐릭터 이름·성격만 공개 시놉시스에서 가져왔고 대사는 예시입니다.
4. **갤러리(컷신·스크린샷)** — DB에 갤러리 이미지가 없어 현재는 공식 키 비주얼(배너·커버)만 "공식 키 비주얼"로 표시합니다.
5. **이미지 해상도** — 메모리얼 서킷 배너가 800×450이라 큰 히어로에서 흐립니다. 시엘라의 사건수기는 커버와 배너가 같은 그림입니다.
6. **번역 누락·오류(DB)** — 대부분 작품의 `genre_en/ja`가 비어 한국어로 표시됩니다. 연혁 2023.04·2023.05의 영어·일본어 제목이 한국어 내용과 다릅니다. 개인정보처리방침은 한국어만 있습니다.
7. **프레스 키트** — 「Memorial Circuit Press Kit」 링크가 `example.com` 자리표시라 "준비 중"으로 보이게 했습니다.
8. **팀** — 프로필 이미지가 없고(이름 첫 글자 칸으로 대체) 안하늘·전성민 소개가 비어 있습니다. 권요한 페이지의 DB에 테스트 섹션("ddad / adadsad")이 있어 스냅샷에서 제외했습니다.
9. **엘리시안 로고** — 설정에는 흰색 마크만 있어, 종이 배경용 먹색 마크는 그 파일을 색만 반전해 만들었습니다(`public/brand/`). 공식 다크 버전이 있으면 교체하세요.
10. **출시일·스토어** — `release_date`가 모두 비어 있어 출시일 행이 숨겨집니다. STOVE는 플랫폼 표기만 있고 링크가 없습니다.
11. **레이블 판별** — `games`에 레이블 컬럼이 없어 `developer`/`series` 문자열로 하봄 작품을 추정합니다. `label` 컬럼 추가를 권장합니다(코드 변경 지점: `lib/labels.ts`).

## 검증

- 타입 검사·`next build`(린트 포함) 통과.
- Playwright 자동 점검 120항목(운영 빌드): 15개 경로 × ko/en/ja × 데스크톱·모바일의 응답·가로 넘침·깨진 이미지·대체 텍스트·h1·런타임 오류, 타이틀 메뉴 키보드, 모바일 메뉴 포커스 가두기·Esc·포커스 복귀, 갤러리·영상 모달, 레이블별 라우팅, 체험 적용 범위, 필터, 언어 전환 유지, 문의 미리보기.
- 정적 미리보기 104항목: 하위 경로 + 엄격한 CSP 환경에서 모든 페이지 하이드레이션·내비게이션·체험·라이트박스·모바일 메뉴.
- 기존 `e2e/` 스펙은 이전 화면 기준이라 이번 시안에 맞춰 갱신하지 않았습니다.
