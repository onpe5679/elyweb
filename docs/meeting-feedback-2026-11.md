# 회의 반영 내역 (시안 D 엘리시안 + 시안 C 하봄)

시안 갤러리 검토 회의에서 정한 방향: **엘리시안은 시안 D(원고와 인덱스)**, **하봄은 시안 C(문학적 타이틀)** 를 기준으로 다듬는다.
이 브랜치(`design/delta-final`)는 시안 D(`design/my-independent-concept`) 위에 시안 C의 하봄 화면을 옮겨 왔다.

| 회의 내용 | 반영 |
| --- | --- |
| 메인 타이틀 "스튜디오 엘리시안"은 원고지 칸 대신 명조로(영어 지원도 고려) | 표지 h1 을 명조(ko/ja)·Cormorant(en)로. 원고지 칸은 하위 페이지 제목에만 남김 |
| "이어 읽기"는 계륵, 메뉴는 소개·작품·새 소식·문의 4개 | 표지 메뉴 = 스튜디오 소개 · 작품 · 새 소식 · 문의. "이야기 시작하기/이어 읽기"와 키보드 안내 문구 삭제 |
| 상단 메뉴 순서 + 프레스 추가 | 스튜디오 소개 · 작품 · 새 소식 · 문의 · 프레스 |
| 종이/밤 테마 전환은 필요 없음 | 토글·밤 테마 CSS 제거 |
| 하봄은 플로팅 버튼으로 | 엘리시안 화면 오른쪽 아래에 하봄 바로가기 버튼(시안 C 색) |
| 작품 목록은 순서 그대로, 하봄은 아래로 빼서 하봄 웹사이트 안내 | 목록 맨 아래에 "하봄 웹사이트 바로가기" 배너 |
| "No.01" 번호 대신 출시 연도(출시 전은 Coming Soon) | 표지 띠·홈 작품·작품 목록. 어드민에 출시일(`release_date`) 입력 추가 |
| "현재 펼쳐진 이야기"를 직접 설정, 일단 시엘라로 | 기존 `is_featured`(어드민 체크박스)로 지정. 미리보기 스냅샷은 시엘라로 바꿈 — **운영 DB는 어드민에서 직접 켜야 함** |
| 팀원 소개는 보류 | 스튜디오 소개에서 팀원 섹션 제거(`/team/*` 페이지는 남아 있음) |
| 연혁은 최신순 | 스튜디오 소개·홈 주요 연혁 모두 최신순 |
| 게임 상세: 연혁 빼고 작품 정보에 "주요 전시" | 연혁 섹션·탭 제거, 전시·선정·수상 항목만 작품 정보에 |
| 제작진은 시안 C 하봄 크레딧 스타일로(엘리시안은 색만 맞춰서), 짧은 OST가 빈칸을 채우게 | 카드+점선 리더, 단마다 쌓는 배치 |
| 스토어 링크는 위로, Steam 로고 | 히어로에 로고 달린 스토어 버튼, 아래 구매 섹션 제거 |
| "도판"은 이상함 → 제목 빼고 이미지만, 옆으로 넘기기(버튼) | 제목 없는 가로 캐러셀 + 좌우 버튼 + 휠 가로 이동 |
| 프레스 페이지에 작품별 자료 섹션 | 스튜디오 자료 + 작품별(키 비주얼·포스터·스토어·작품별 프레스 키트) |
| 문의는 폼 없이 이메일만 | 문의 페이지 = 대표 메일 + 복사 버튼 + SNS |
| AI 티 줄이기 | "도판" 캡션, 메뉴 번호, "이번 호", 키보드 안내 등 장식 문구 정리 |

## 남은 일 / 확인 필요

- **대표 메일**: 회의에서 `contact@studioelysian.co` 를 요청함. 메일함이 만들어지면 어드민 설정의 `contact_email` 만 바꾸면 문의·푸터·프레스에 모두 반영된다(코드 수정 불필요).
- **대표작(시엘라)**: 운영 DB에서는 어드민 → Games 에서 시엘라의 Featured 를 켜고 메모리얼 서킷을 끈다.
- **출시일 컬럼**: `games.release_date` 는 초기 스키마(001)에 있는 컬럼이다. 운영 DB에 그대로 있는지 확인 후 어드민 입력칸을 쓴다.
- **하봄 미니 체험**: 시안 C의 짧은 예시 대본. 실제 리소스(스탠딩·UI)를 받으면 같은 자리에서 교체한다.
- **하봄 전용 도메인**: 지금은 `/habom` 경로. 나중에 서브도메인으로 분리할 수 있다.

## 어드민 개편 (새 사이트 구조에 맞춤)

DB 구조는 바꾸지 않았다(기존 컬럼만 사용) — 지금 운영 중인 사이트와 같은 DB를 그대로 써도 안전하다.

| 바뀐 점 | 내용 |
| --- | --- |
| 대시보드 "사이트 구조 안내" | 새 사이트 화면(메인·작품·게임 상세·하봄·스튜디오 소개·새 소식·문의·프레스)별로 어느 메뉴의 어떤 값이 쓰이는지 정리. 메인 대표작을 여기서 바로 선택 |
| 메인 대표작 단일 지정 | 대시보드 선택 / 작품 목록의 "대표작으로" 버튼 / 작품 편집에서 켜고 저장 — 어느 쪽이든 한 작품만 `is_featured` 로 남고 나머지는 자동 해제 |
| 메뉴 | 한국어, 사이트 순서: 작품 → 스튜디오 연혁 → 새 소식 → 프레스 자료 → 사이트 설정 → 팀원(보류·미노출) → 이전 문의 폼 기록 → 관리자 계정 |
| 작품 | 목록에 소속(엘리시안/하봄)·출시일·대표작 표시. 편집 화면을 기본 정보 / 이미지 / 출시·스토어 / 노출 / 상세 섹션으로 나누고 각 칸이 웹 어디에 쓰이는지 설명. 하봄 작품이면 안내 배너 |
| 상세 섹션 | 종류 이름을 웹 위치 기준으로(글=소개, 이미지=캐러셀, 제작진=크레딧 카드, 연혁=출시일·주요 전시 계산용, 스토어=상단 버튼). 섹션을 고르면 "웹에서 보이는 곳" 안내 |
| 스토어 로고 | 스토어 섹션에서 고른 로고(Steam/STOVE/itch.io)를 웹 상단 버튼에 그대로 사용 |
| 사이트 설정 | 키마다 분류·웹에서 보이는 곳 표시, 새 사이트에서 안 쓰는 키(logo_mark_dark, vision_image 등)는 회색 "사용 안 함" |
| 프레스 자료 | 작품을 비우면 스튜디오 공통 자료, 작품을 고르면 작품별 칸 |
| 미리보기 모드 | `VITE_ADMIN_PREVIEW=1` 로 빌드·실행하면 웹 스냅샷 데이터로 동작(브라우저 메모리, 저장 안 됨). 공개 시안 주소에서 어드민 구성을 안전하게 보여 주는 용도. 실제 빌드 번들에는 포함되지 않음 |

검증: `apps/admin` 타입체크 0 오류, 실제/미리보기 두 모드 빌드 성공, `e2e/admin-preview.spec.ts` 6건 통과.
