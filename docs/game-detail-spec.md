# 게임 상세 공통 규격

작품 상세(`/[locale]/games/[slug]`)는 스트리밍 서비스의 작품 소개 화면(레퍼런스 `07`, `08`)의 **정보 위계**를 게임 소개에 옮긴 규격입니다.
담당자는 어드민(기존 `games`, `game_sections`)에 아래 표대로 채우면 되고, **채우지 않은 칸은 화면에서 통째로 사라집니다**(가짜 문구·빈 칸을 만들지 않음).

## 1. 화면 구성

```
┌ 히어로 ─────────────────────────────────────────────┐
│ 작품 > 시리즈          (큰 비주얼 = banner_image)   ┌──────┐│
│ [시리즈] [상태]                                      │포스터││
│ 작품명                                               │cover ││
│ 한 줄 소개(description)                              └──────┘│
│ 플랫폼 · 장르                                               │
│ [스토어 보기 ↗] [체험하기*] [영상 보기] [공식 사이트 ↗]      │
└───────────────────────────────────────────────────┘
탭(고정): 소개 · 도판 · 영상 · 제작진 · 연혁 · 다른 작품   ← 내용이 있는 것만 표시
소개 ─ 시놉시스/특징 글 (왼쪽 7칸)   │ 작품 정보 · 스토어 버튼 (오른쪽 4칸)
도판 ─ 키 비주얼·포스터·갤러리(클릭 시 라이트박스)
영상 ─ YouTube 카드(PV·OP·ED·데모 등)
제작진 ─ 그룹별(제작진 / 성우 / OST 등) 정의 목록
연혁 ─ 프로젝트 연혁
다른 작품 ─ 같은 시리즈(없으면 같은 브랜드)의 다른 작품
```
`*` 체험하기 버튼은 하봄 소속 게임에만 나타납니다.

## 2. 어드민 입력 → 화면 슬롯

### `games` (작품 기본 정보)

| 필드 | 화면 슬롯 | 비고 |
| --- | --- | --- |
| `title_ko/en/ja` | 작품명(히어로 h1, 목록, 메타) | 줄바꿈 가능(`\n`) |
| `series_ko/en/ja` | 시리즈 마커, 작품 정보, 목록 필터 | 엘리시안 시리즈명 또는 **하봄 소속이면 "하봄 스튜디오"** (→ 브랜드 판별) |
| `description_*` | 히어로 한 줄 소개, 목록 카드 소개 | 2~3문장 권장 |
| `status` | 상태 라벨 | released / coming_soon / in_development / publishing |
| `banner_image` | 히어로 큰 비주얼(가로) | 16:9, 1920×1080 이상. 없으면 `cover_image` 사용 |
| `cover_image` | 히어로 오른쪽 포스터, 도판 | 3:4 세로 권장 900×1200 이상 |
| `thumbnail_image` | (백업) 목록 이미지 | 보통 `cover_image` 와 같게 둠 |
| `genre_*` | 작품 정보 · 히어로 메타 | 배열 |
| `platforms` | 작품 정보 · 히어로 메타 | 예: `PC`, `Steam` |
| `steam_url` | 스토어 버튼(스토어 섹션이 없을 때) | |
| `official_url` | "공식 사이트" 버튼 | |
| `is_featured` | 홈의 "이번 호" 대표 작품 | 엘리시안 소속 작품만 홈 대표가 됨 |
| `display_order` | 목록·표지 스트립 순서 | |

### `game_sections` (여러 개, `display_order` 순)

| `section_type` | 화면 슬롯 | 채우는 법 |
| --- | --- | --- |
| `text` / `custom` | **소개** 탭의 글 블록 | 제목에 "시놉시스/Synopsis/あらすじ/줄거리"가 들어가면 시놉시스 라벨이 붙음. 아래 3번 서식 지원 |
| `gallery` | **도판** 탭 | `images` 에 URL 배열. 컷신·스크린샷 |
| `video` | **영상** 탭 | `video_url` 에 YouTube 주소. 섹션 하나당 영상 하나(제목 = 카드 이름) |
| `credits` | **제작진** 탭 | 섹션 하나 = 그룹 하나(예: "제작진", "성우 크레딧", "Vocal OST"). 첫 그룹의 위 3줄이 "작품 정보"에도 요약됨 |
| `timeline` | **연혁** 탭 + 작품 정보의 "출시" | 항목 문구에 "출시/release"가 있으면 출시일로 사용(Steam 우선). 이모지는 화면에서 제거 |
| `store` | 스토어 버튼(히어로·작품 정보) | `store_links` 의 이름·URL. 첫 링크가 히어로의 주요 버튼 |

## 3. 글 서식(소개 탭)

- 빈 줄 = 문단 나눔. 한 줄 줄바꿈은 그대로 유지(시놉시스처럼 짧은 줄로 쓰는 글 지원).
- `[소제목]` 으로 시작하는 문단 → 소제목 + 본문.
- `•`, `-`, `1.` 로 시작하는 줄들 → 목록.

## 4. 소속(브랜드) 판별과 체험 기능

- 작품의 소속은 `series_*` 또는 개발사 문구에 **"하봄 / Habom / ハボム"** 가 들어 있으면 하봄, 아니면 엘리시안입니다(`apps/web/lib/brands.ts`). DB 변경 없이 동작하며, 나중에 `games.brand` 컬럼을 두면 `resolveBrand` 한 곳만 바꾸면 됩니다.
- 하봄 소속이면 상세 페이지가 하봄 테마(핑크·둥근 모서리)로 바뀌고 **대사·선택지 체험**이 활성화됩니다. 엘리시안 작품에는 나타나지 않습니다.
- 새 산하 스튜디오를 추가하려면 `BRANDS` 에 항목을 더하고 `globals.css` 에 `[data-brand="<id>"]` 토큰을 추가합니다.

## 5. 비어 있을 때

| 비어 있는 것 | 결과 |
| --- | --- |
| 글 섹션이 없음 | 한 줄 소개(`description`)를 소개 탭에 표시 |
| 갤러리 없음 + banner/cover 가 같은 이미지 | 도판 탭 숨김 |
| 영상 없음 | 영상 탭·"영상 보기" 버튼 숨김 |
| 크레딧/연혁 없음 | 해당 탭 숨김 |
| 스토어 링크·`steam_url` 없음 | 스토어 버튼 숨김 |
| 같은 브랜드의 다른 작품 없음 | "다른 작품" 숨김 |

## 6. 작품 하나 채우기 체크리스트

1. `games`: 제목·시리즈·한 줄 소개·상태·배너·커버·(장르·플랫폼)
2. `game_sections`: 시놉시스(text) → 특징(text) → 갤러리(gallery) → 영상(video) → 제작진(credits…) → 연혁(timeline) → 스토어(store)
3. 세 언어(ko/en/ja)를 모두 채우거나, 비워 두면 한국어로 대체됩니다.
4. 상세 화면에서 탭이 모두 의도대로 나타나는지 확인합니다.
