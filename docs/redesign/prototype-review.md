# 엘리시안 리디자인 시안

작성일: 2026-10-21. 실제 작품과 공개 콘텐츠를 연결한 반응형 웹 시안.

## 📍 미리보기

원격 접속용 임시 미리보기:

- [엘리시안](https://techno-perception-minister-cover.trycloudflare.com/ko)
- [하봄](https://techno-perception-minister-cover.trycloudflare.com/ko/habom)
- [게임 상세·선택지 체험](https://techno-perception-minister-cover.trycloudflare.com/ko/games/sharehouse)

로컬 시안 서버를 임시 HTTPS 터널로 연결했다. 화면과 상호작용을 검토할 수 있고, 미리보기 프록시에서는 문의 전송 등 쓰기 요청을 받지 않는다. 서버·터널 실행 중 유효한 주소이며 운영 도메인 배포와는 별개다.

| 화면 | 로컬 주소 | 확인할 내용 |
| --- | --- | --- |
| 엘리시안 | http://localhost:3100/ko | 문예적인 첫 화면, 이야기 펼치기, 작품 필터, 하봄 이동 |
| 작품 목록 | http://localhost:3100/ko/games | 엘리시안 작품과 시리즈별 필터 |
| 하봄 | http://localhost:3100/ko/habom | 별도의 브랜드 분위기와 작품 소개 |
| 하봄 게임 상세 | http://localhost:3100/ko/games/sharehouse | 스트리밍형 상세, 트레일러, 이미지 확대, 짧은 선택지 체험 |
| 엘리시안 게임 상세 | http://localhost:3100/ko/games/memorial-circuit | 공통 작품 소개 규격, 하봄용 체험 제외 |
| 스튜디오 | http://localhost:3100/ko/about | 소개, 실제 팀원, 연혁 |
| 소식·문의·프레스 | `/ko/news`, `/ko/contact`, `/ko/press` | 기존 콘텐츠·기능과 연결한 편집 디자인 |

`/en`, `/ja`에서도 화면을 제공한다. 언어 선택은 현재 페이지를 유지한다. 로컬 주소는 이 작업 환경에서 실행 중인 미리보기이며, 운영 도메인에 배포한 주소가 아니다.

## 🎯 디자인과 상호작용

- 엘리시안은 종이색 바탕, 명조체, 여백, 얇은 원고지 선을 사용한다. 첫 화면의 ‘이야기 펼치기’는 작품 영역으로 이동하며, 진입 시 작품 이미지가 나타나는 절제된 연출을 더했다.
- 실제 작품 이미지를 크게 보여 주고, 작품명·장르·상태·짧은 소개의 정보 위계를 통일했다. 엘리시안 목록과 하봄 작품을 분리하고 두 브랜드 사이의 이동을 제공한다.
- 하봄은 크림색, 핑크, 연노랑과 둥근 화면 요소를 사용한다. 실제 로고 자료가 확인되지 않아 로고를 임의로 창작하지 않고 텍스트로 이름을 표시했다.
- 게임 상세는 큰 배경 그림과 작품명·주요 버튼, 시놉시스·기본 정보, 아트워크·영상·제작진·연혁·관련 작품으로 구성한다. 제공된 콘텐츠가 없는 섹션은 비워 두거나 사실처럼 채우지 않는다.
- 대사·선택지 체험은 하봄 소속 게임 상세에만 표시한다. 두 선택지, 서로 다른 응답, 이전 장면, 다시 선택, 종료를 제공한다. 실제 게임 대본이 제공되지 않아 ‘인터랙션 시안 · 예시 대사’임을 명시한다.
- 영상·이미지·체험 창은 키보드와 Escape를 지원하고 닫힌 뒤 시작 버튼으로 포커스를 돌려준다. 동작 줄이기 설정에 대응한다.

기존 관리자·데이터베이스는 수정하지 않았다. 운영 콘텐츠를 읽어 표시하며 시안의 일부 브랜드 문구는 코드에 작성했다. 추후 시안 확정 후 관리자에서 편집할 신규 문구·체험 콘텐츠 항목을 정할 수 있다.

| 작품 필터·상세 이동 | 통과 |
| 하봄 체험의 두 분기·재선택·Escape·포커스 복귀 | 통과 |
| 모바일 메뉴·현재 페이지를 유지하는 언어 전환 | 통과 |
| 소개·문의·프레스·소식·팀·개인정보 페이지 | 주요 데스크톱·모바일 경로 수동 확인 |
| 문의 폼 | 요청을 모킹해 입력·성공 화면 확인. 테스트 메일 발송이나 DB 입력 없음 |
| 기존 로컬 계약 테스트 | 변경 전과 후 모두 17개 중 11개 통과·6개 실패. 새 실패 없음. 해당 미추적 테스트·스크립트는 이 시안 커밋에 포함하지 않음 |

기존 계약 테스트의 실패는 연혁 활성 필터, DB 게임 상태 필터, 기존 이미지 마이그레이션 매핑, 이전 Hero 컴포넌트의 누락 이미지, 헬스 엔드포인트, Compose 헬스체크다. 기준 커밋 `79deebe`를 별도 임시 디렉터리에 풀어 같은 테스트를 실행해 동일함을 확인했다. 이 시안에서 해당 범위는 변경하지 않았다.

외부 영상 썸네일이 로드되지 않으면 실제 작품 배너로 대체한다. 프레스 자료의 기존 `example.com` 예시 링크는 다운로드 버튼 대신 준비 중으로 표시한다. 실제 다운로드 링크는 유지한다.

## ✍️ 남은 콘텐츠 결정

디자인 시안과 기능 검증은 완료했다. 실제 하봄 체험에 쓸 작품 장면·대본·선택지·사운드, 하봄의 전용 브랜드 원본, 운영 반영 시 새 문구의 관리자 편집 항목은 별도 콘텐츠 작업으로 남는다. 운영 사이트 배포는 수행하지 않았다.

개발 미리보기 재실행: `pnpm --filter web dev --port 3100`. 현재 같은 포트에 미리보기가 실행 중이면 먼저 해당 프로세스를 종료한 뒤 실행한다.
